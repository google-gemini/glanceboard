Let's get your AI calendar art set up in a few steps.

Enter your city or suburb so we can show the weather and dress characters appropriately.

4. You're all set! 🎉

Your Glanceboard is configured and ready to generate.

Setup Guide

          

            
1

              
🔑 Get an API Key

              
    
                
  1. Go to aistudio.google.com/apikey
    2. 
                
  2. Click Create API Key → select your Google Cloud project
    3. 
                
  3. Copy the key and paste it in Settings
    4. 
              

            

            
2

              
📅 Connect Your Calendar

              
    
                
  1. Go to Google Calendar Settings
    2. 
                
  2. Click your calendar → "Secret address in iCal format"
    3. 
                
  3. Copy the URL and paste it in Settings
    4. 
              

            

            
3

              
🌤️ Set Your Location

              
Enter your city in Settings so we can show weather and dress characters appropriately.

            

            
4

              
🎨 Generate!

              
Go to the Dashboard and click "🎨 Generate Now" to create your first calendar art image.

            


            


            

              
📺 E-Ink Display Setup

              
Connect your Waveshare ESP32-S3 PhotoPainter display to auto-fetch generated images.


              

                
Display Image URL

                
Auto-generated from your account. Your PhotoPainter fetches this URL to update the display.

                

                  
                  
                

                

                  
                  
                

                
💡 The display URL is auto-generated from this page's address. If you're hosting this file on a server (e.g. python -m http.server 8000), your display can fetch from this URL directly.

              


              
To set up your Waveshare ESP32-S3 PhotoPainter display:


              
Step 1: Flash the firmware

              
    
                
  1. Connect the PhotoPainter to your computer via USB-C
    2. 
                
  2. Open the Glanceboard Web Flasher in Chrome or Edge
    3. 
                
  3. Click Install Glanceboard Firmware and select your device
    4. 
                
  4. Wait for the flash to complete (~2 minutes), then unplug and replug the USB cable
    5. 
              


              
Step 2: Connect to WiFi & configure

              
    
                
  1. The display shows a setup screen with the WiFi name Glanceboard-XXXX
    2. 
                
  2. On your phone/computer, connect to the Glanceboard-XXXX WiFi (no password)
    3. 
                
  3. A setup page opens automatically (or go to http://192.168.4.1)
    4. 
                
  4. Enter your WiFi credentials
    5. 
                
  5. Paste the Display Image URL from above (📋 Copy URL)
    6. 
                
  6. Choose a poll interval and click Save & Connect
    7. 
              

              
The device restarts, connects to WiFi, and starts polling for images. The display updates within ~60 seconds.


              
💡 Using a Raspberry Pi instead? See the Glanceboard GitHub for the legacy Pi setup guide.
