Welcome to Glanceboard

Let's get your e-ink display set up in a few steps.

1. AI Image Generation

Glanceboard uses Nano Banana to generate your calendar art. You'll need a Gemini API key.

Get one at Google AI Studio → Create API Key

2. Calendar

Paste your calendar's iCal URL so Glanceboard can read your events.

💡 Google Calendar: Settings → your calendar → "Secret address in iCal format"

Works with Google Calendar, Outlook, Apple Calendar, or any iCal feed.

3. Weather

Enter your city or suburb so we can show the weather on your display and dress the characters appropriately.

4. You're all set! 🎉

Your Glanceboard is configured. Images generate automatically at 1 AM and 2 PM daily.

📺 Set Up Your Display

Flash the community firmware onto your Waveshare PhotoPainter and connect it to your Glanceboard.

  1. Connect your PhotoPainter via USB-C and flash using the web flasher in Chrome
  2. Scan the QR code on the device to connect it to your WiFi
  3. Go to photoframe.local → Settings → Auto Rotate
  4. Enable Auto-Rotate, set Rotation Mode to Fetch image from URL
  5. Paste your Display Image URL (from Settings → 📋 Copy URL) and save

Setup Guide

        


        

          
          

            
1

            

              
🛒 Get the PhotoPainter

              
You just need one thing — the display itself:

              

                

                  🖼️
                  

                    Waveshare ESP32-S3 PhotoPainter
                    
7.3" colour e-ink display in a beautiful wooden frame with built-in WiFi, speaker, and sensors. ~$90 from Waveshare or Amazon.

                  

                

                

                  🔌
                  

                    USB-C Cable
                    
For power — or use the optional lithium battery for cable-free operation.

                  

                

              


            

          


          
          

            
2

            

              
📶 Connect to WiFi

              
    
                
  1. Power on the PhotoPainter — a setup screen with QR codes appears
    2. 
                
  2. Scan the QR code on the device with your phone
    3. 
                
  3. Follow the prompts to connect the PhotoPainter to your local WiFi
    4. 
              

            

          


          
          

            
3

            

              
⚙️ Configure the Display

              
On a computer connected to the same WiFi network:

              
    
                
  1. Go to photoframe.local in your browser (or scan the QR code — but a computer is easier)
    2. 
                
  2. Scroll down to Settings and click the Auto Rotate tab
    3. 
                
  3. Enable Auto-Rotate
    4. 
                
  4. Under Rotation Mode, select URL - Fetch image from URL
    5. 
                
  5. Copy the URL from Settings → E-Ink Display Setup → 📋 Copy URL in the Glanceboard dashboard and paste it into the Image URL field on the display
    6. 
                
  6. Set a wake schedule (e.g. every 12 hours) to control how often the display refreshes
    7. 
                
  7. Click Save
    8. 
              

              

                
Here's what the Waveshare display settings look like:

                

                  

                    
                    
Enable Auto-Rotate and set a schedule

                  

                  

                    
                    
Set Rotation Mode to "URL" and paste your URL here

                  

                

              

            

          


          
          

            
4

            

              
🎨 Generate Your First Image

              
    
                
  1. Come back to this dashboard
    2. 
                
  2. Go to the Dashboard page
    3. 
                
  3. Click "🎨 Generate Now"
    4. 
                
  4. Your first calendar art image will be created and the display will fetch it automatically!
    5.
